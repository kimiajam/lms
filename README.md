# Simple LMS

A simple Learning Management System built with Django.

## Features

* User registration and login
* Automatic user profiles
* Course browsing
* Course enrollment
* Lessons and course content
* My Courses
* Django Admin
* Responsive design

## Tech Stack

* Python
* Django
* SQLite
* HTML
* CSS

## Run Locally

```bash
git clone <your-repository-url>
cd LMS

python -m venv venv
source venv/bin/activate

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Then open:

`http://127.0.0.1:8000/`
